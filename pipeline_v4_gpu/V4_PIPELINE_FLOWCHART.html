Signal Computation

A

Signal A: PySceneDetect — AdaptiveDetector, binary boundary signal. Weight: 0.35

B

Signal B: DINOv2 Embeddings — L2 distance between consecutive frames, normalized 0-1. Weight: 0.45

C

Signal C: OCR Jaccard — Jaccard distance of OCR word sets between consecutive samples (every 0.5s). Weight: 0.20

combined = 0.35 × signal_A + 0.45 × signal_B + 0.20 × signal_C
(If no OCR signal: reweight A + B only)

Priority Cascade (per keyword)

Is keyword groundable AND has t_narr? — If no → Case F
A
OCR at t_narr (visual present in current scene)
Union of all OCR words across scene → fuzzy match keyword (threshold 0.80)
Find earliest frame with keyword in scene
t_vis = earliest_frame | delta_t = t_vis - t_narr ≤ 0 | alpha = 1.0 (full) / 0.8 (partial)
Sub-case D: keyword onset >1s after scene start (progressive reveal)
↓ not found → try Case B
B
Forward search +10s (visual appears late)
Search OCR frames in [t_narr+1s, t_narr+10s]
delta_t = t_vis - t_narr > 0 → penalized | alpha = 1.0 / 0.8
↓ not found → try Case C
C
Backward search -10s (visual expired)
Search OCR frames in [t_narr-10s, t_narr-1s], scene must have ended
delta_t = 10.0 (capped) | alpha = 0.8 | confidence = MEDIUM
↓ not found → try Case E
E
Gemini Concept Match V4
Search scenes ±10s → match keyword against gemini_concepts (pipe-separated)
Matching: exact substring OR rapidfuzz token_set_ratio ≥ 75
alpha = 0.6 + 0.3 × (score/100) ∈ [0.6, 0.9] | confidence = MEDIUM/HIGH
Records: gemini_concept_matched, gemini_match_score
↓ not found → try Case G
G
SigLIP Visual Match (no text, reduced alpha)
Embed keyword as "A visual showing {kw}" + embed keyframe images
Sigmoid similarity × temporal Gaussian weight (σ=5s)
Threshold: SIGLIP_KEYWORD_MIN_SIM = 0.55
alpha ∈ [0.1, 0.5] (scaled by similarity margin) | confidence = LOW
↓ not found → Case F
F
No Visual Correlate (excluded from scoring)
Sub-classify reason: ocr_vocabulary_mismatch | no_ocr_nearby | low_groundability
alpha = 0 | t_vis = None | delta_t = None
Asymmetric delta_t (Visual Persistence Verified): V4
delta_t = t_vis - t_narr

delta_t ≤ 0 AND visual_on_screen = True → Score = 100 (simultaneous presentation)
delta_t ≤ 0 AND visual_on_screen = False → penalized by |delta_t| (visual expired)
delta_t > 0 → visual appears AFTER narration → penalized by scoring formula

Visual persistence verification per case:
• Case A/D: keyword in current scene OCR union → scene active at t_narr → True
• Case E/G: matched scene.t_start ≤ t_narr ≤ scene.t_end → True; else False
• Case C: scene ended before t_narr → False (expired)
• Case F: no match → False

Theoretical basis: Mayer (2009) Temporal Contiguity Principle — score 100 is justified
because the visual IS still on screen when narration occurs (verified, not assumed).

Scoring Formulas (Asymmetric, Visual-Persistence Verified) V4

Gaussian (primary):
if delta_t ≤ 0 AND visual_on_screen = True: S = 100   (simultaneous → no penalty)
if delta_t ≤ 0 AND visual_on_screen = False: S = 100 × exp(-0.5 × (|delta_t| / τ)²)   (expired visual)
if delta_t > 0: S = 100 × exp(-0.5 × (delta_t / τ)²)   τ = 2.5s

Piecewise (alternative):
Same logic: visual_on_screen = True → 100; else piecewise on |delta_t|
|Δt| ≤ 1s → 100  |  1-3s → 100 - 15(|Δt|-1)  |  3-5s → 70 - 35(|Δt|-3)  |  >5s → 0

Floor formula:
S_final = S_raw × (0.5 + 0.5 × alpha)

Weighted score:

Sensitivity Analysis (Post-Pipeline) V4
Input
transcript_segments_improved.csv, keywords.csv, keyword_alignment.csv
Output
sensitivity/weight_perturbation.csv, sensitivity/ablation.csv, sensitivity/scoring_impact.csv, sensitivity/sensitivity_summary.json

Purpose

Tests whether final scores are robust to heuristic weight perturbations. If scores are stable across ±50% weight changes, the specific weight values matter less than the feature set — a strong defense against "arbitrary weights" criticism.

Analysis Components

1

Weight Perturbation: Vary each of 6 features ±25%/±50% (re-normalize to sum=1.0). Measure Spearman rank correlation vs baseline. Target: ρ > 0.9 = robust.

2

Feature Ablation: Leave-one-out for each feature + V3-equivalent (3 features only). Shows marginal contribution of each V4 feature.

3

End-to-End Scoring Impact: Propagate weight changes through importance → scoring → overall video score. Report CV% — target: <5% = stable.

4

Feature Correlations: Pairwise correlation matrix to check multicollinearity between the 6 features.

Theoretical grounding per feature:
Keyword density → Cognitive Load Theory (Sweller, 1988)
Speech rate → Segmenting Principle (Mayer, 2009)
Word count → Element interactivity (Sweller & Chandler, 1994)
Instructional verbs → Bloom's Taxonomy (Anderson & Krathwohl, 2001)
Discourse signals → Signaling Principle (Mayer, 2009; Lemarié et al., 2008)
First-mention → Schema Theory / novelty processing (Piaget; Tulving, 1972)

Run via: --sensitivity-analysis flag or standalone: python -m pipeline_v4_gpu.utils.sensitivity_analysis --output-dir outputs_v4/VIDEO
